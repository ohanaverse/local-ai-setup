# claude-session-skills

Skill and system-prompt text recovered from Claude Code **session transcripts**
(the text the harness actually put in front of the model during a session).

This is a different capture of similar material from
[`../claude-embedded/`](../claude-embedded/), which `bin/extract-claude-skills`
pulls out of the Claude Code **binaries**:

| | `claude-embedded/` | `claude-session-skills/` |
|---|---|---|
| Source | embedded template literals in a Claude Code version binary | a session record, as sent to the model |
| Produced by | `bin/extract-claude-skills` (repeatable per version) | extracted by hand from sessions captured with `litellm-session-logs/03_capture_claude_code.sh` and rebuilt with `build_cc_transcript.py` |
| Text | every markdown block found, with JS artifacts cleaned up | the rendered text, with arguments and environment substituted |

Use `claude-embedded/` to see what a given version ships. Use this directory
for the rendered form a session saw, and for the main system prompts
(`system-prompt.md`, `system-prompt-code-review-agent.md`), which have no
counterpart in `claude-embedded/`. The `code-review-*`, `init` and
`revise-claude-md` files overlap with `claude-embedded/` but are not
byte-identical; neither set is canonical, so compare against a version's
binary extraction before relying on either.

These files are snapshots of one point in time and are not regenerated by any
tool in this repo.
