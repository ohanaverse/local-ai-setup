# agy-wt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `agy-wt` — an interactive worktree launcher for the Antigravity CLI (`agy`) — following the existing `*-wt` wrapper pattern.

**Architecture:** A thin bash wrapper (`bin/agy-wt`) sources `wt-core.sh` and defines agent-specific callbacks (`wt_check_deps`, `wt_yolo_flag`, `wt_exec`). No model passthrough because `agy` has no `--model` CLI flag. Update `bin/README.md` to document the new launcher.

**Tech Stack:** bash, git, fzf, agy

### Task 1: Create `bin/agy-wt` wrapper script

**Files:**
- Create: `bin/agy-wt`

- [ ] **Step 1: Write the wrapper script**

Create `bin/agy-wt` with the following exact content. It mirrors `pi-wt` (the simplest existing wrapper) with `agy`-specific strings.

```bash
#!/usr/bin/env bash
# agy-wt — launch Antigravity CLI in a chosen worktree or branch.
# Usage: agy-wt [-w/--worktree <name>] [--yolo] [agy-args...]
#
# Install: copy to ~/.local/bin/agy-wt alongside wt-core.sh.

set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"

if [[ ! -f "$SCRIPT_DIR/wt-core.sh" ]]; then
  printf '%s: wt-core.sh not found at %s/wt-core.sh\n' "$(basename "$0")" "$SCRIPT_DIR" >&2
  printf '%s: Ensure both wt-core.sh and %s are copied to the same directory.\n' "$(basename "$0")" "$(basename "$0")" >&2
  exit 1
fi

source "$SCRIPT_DIR/wt-core.sh"

WT_NAME="$(basename "$0")"

wt_check_deps() {
  command -v agy >/dev/null 2>&1 || die "agy not found. Install: curl -fsSL https://antigravity.google/cli/install.sh | bash"
}

wt_yolo_flag() {
  echo "--dangerously-skip-permissions"
}

wt_exec() {
  # agy does not accept --model on the CLI (model selection is done
  # inside the TUI via /model), so we do not implement AI_CODING_MODEL
  # passthrough here.
  exec agy "$@"
}

wt_main "$@"
```
